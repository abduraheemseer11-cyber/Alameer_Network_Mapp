# خريطة شبكة الأمير (Al-Amir Network Map)
**تطبيق الخرائط الجغرافية لإدارة وتتبع شبكات الإنترنت السلكية واللاسلكية**
**للمهندس: عبدالرحيم الماخذي**

---

## 🌟 نظرة عامة (Overview)
تطبيق أندرويد أصلي (Native Android) مصمم خصيصاً لمهندسي وفنيي شبكات الإنترنت (WISP / ISP) لحل مشكلة تحديد مواقع الأجهزة ومودمات المشتركين وصناديق التوزيع (Waterproof Boxes) والأنتينات الخارجية في الميدان.
يعمل التطبيق بشكل كامل **دون الحاجة للاتصال بالإنترنت (Offline-First)** مع خريطة أقمار صناعية مجانية عالية الدقة دون تكاليف أو رسوم لـ Google Maps.

---

## 🛠️ المميزات الرئيسية (Core Features)

1. **خريطة الأقمار الصناعية (Satellite View & Offline Cache):**
   - خريطة تفاعلية تعرض صور الأقمار الصناعية العالمية المجانية (Esri World Imagery) وشوارع OpenStreetMap.
   - نظام كاش ذكي (Tile Cache) يحفظ المناطق التي تمت معاينتها للعمل دون إنترنت أثناء الصيانة الميدانية.
   - إمكانية التبديل إلى وضع الشبكة التخطيطية (Offline Grid) لتوفير البيانات.

2. **علامات الأجهزة (Visible Badges):**
   - كل جهاز على الخريطة يحمل شارة واضحة ودائمة تعرض: **رقم الشبكة (#105) - اسم العميل / الجهاز**.
   - ألوان مميزة للحالات:
     * 🟢 **أخضر**: يعمل بشكل سليم.
     * 🔴 **أحمر**: عطل / سلك مقطوع / بدون خدمة.
     * 🟠 **برتقالي**: قيد الصيانة والتجهيز.
   - تمييز الأجهزة حسب النوع (روتر مايكروتك دمج وتوزيع، صندوق وتر بروف مع سوتش، أنتينة لاسلكية، مودم منزلي).

3. **البحث السريع والتحديد الفوري (Instant Search):**
   - بمجرد اتصال العميل وإعطاء رقم الشبكة (مثلاً `105`)، يكتب المهندس `105` في شريط البحث.
   - تتوجه الخريطة فوراً إلى منزل العميل بدقة عالية مع وميض نابض وفتح بطاقة التفاصيل.

4. **بطاقة التفاصيل الكاملة (Device Details Sheet):**
   - اسم العميل ورقم الهاتف مع زري اتصال مباشر ومحادثة واتساب سريعة.
   - عنوان IP مع زر نسخ وزر لفتح لوحة تحكم المودم بالمتصفح (`http://IP`).
   - اسم المستخدم وكلمة المرور المشفرة مع إمكانية الكشف والنسخ.
   - صندوق الوتر بروف المغذي ورقم المنفذ (Port) وطول السلك.
   - زر التوجيه والملاحة المباشرة عبر GPS (`geo:lat,lng`).

5. **أداة قياس المسافة الحية (Distance Measurement Tool):**
   - تتيح لمس أي نقطتين أو أكثر على الخريطة لحساب المسافة الدقيقة بين الكامبات ومنازل العملاء بالأمتار والكيلومترات لمعرفة طول السلك المطلوب.

6. **النسخ الاحتياطي وحماية البيانات (Backup & Privacy):**
   - خصوصية مطلقة: البيانات محفوظة محلياً في قاعدة بيانات Room المشفرة ومرتبطة بحساب Google للمالك فقط.
   - تصدير كامل لقاعدة البيانات في ملف محمول واحد (`JSON`) لمشاركته وحفظه في Google Drive أو واتساب.
   - استعادة سريعة للبيانات في أي وقت عند تبديل الهاتف.

## 🏗️ البنية التقنية (Architecture)
- **لغة البرمجة:** Kotlin (100% Native)
- **واجهة المستخدم:** Jetpack Compose (Material Design 3) مع دعم كامل لاتجاه اليمين لليسار (RTL)
- **قاعدة البيانات:** Room Database (SQLite)
- **المحرك الجغرافي:** Custom Compose Canvas Mercator Projection Engine + OkHttp Tile Disk Cache
- **المصادقة:** Firebase Authentication & Jetpack Credential Manager
- **الأمان والتشفير:** AES/CBC/PKCS5Padding لتشفير كلمات المرور عند الحفظ في قاعدة البيانات
